# sbti.lingyi.tools

SBTI 测试免费入口静态页。

## 说明

- 本项目页面基于用户提供的信息整理制作
- 页面内容参考所提供站点与入口信息进行呈现
- 本页仅用于访问入口汇总与跳转展示
- 源码托管：GitHub
- 部署平台：Cloudflare Pages
- 自定义域名：sbti.lingyi.tools
- 目标链接：https://sbti.unun.dev/

## Cloudflare Pages 部署建议

1. 将本目录上传到 GitHub 仓库
2. 在 Cloudflare Pages 中连接该 GitHub 仓库
3. Framework preset 选择 `None`
4. Build command 留空
5. Output directory 填写 `/` 或仓库根目录
6. 部署完成后绑定自定义域名 `sbti.lingyi.tools`

## 页面备注建议

> 本页面基于用户提供的信息整理制作，展示内容参考所提供站点与入口信息，仅用于访问入口汇总与跳转展示，不构成对原测试系统的原创声明。
